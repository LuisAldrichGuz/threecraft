# Créditos de texturas

Las texturas de bloques de este juego son del resource pack **Faithful 32x**
(rama Java 1.21.11), usadas bajo la Faithful License (ver
`LICENSE-FAITHFUL.txt` y https://faithfulpack.net/license).

- Faithful: https://faithfulpack.net
- Repo: https://github.com/Faithful-Resource-Pack/Faithful-32x-Java

Cambios hechos aquí: se copiaron sólo los bloques que el juego usa (carpeta
`assets/minecraft/textures/block`), se recortó el primer fotograma de las
texturas animadas (agua, lava) y se aplicaron los tintes de bioma de Minecraft
(pasto #91BD59, hojas #77AB2F, abedul #80A755, abeto #619961, agua #3F76E4),
que en el pack original vienen en gris para que el juego los coloree.
